# GOAT Hoopers selected hybrid

Approved Round 02 combination: the selected horn-and-basketball emblem,
Clubhouse lettering and warm colors. This directory contains the production
assets from `GOAT-HOOPERS-Selected-Hybrid.zip`: 15 editable SVGs and their
21 transparent PNG exports, including the supplied 16/32/64 px micro marks.

`assets/` keeps the original filenames and bytes. Primary, horizontal,
emblem and micro variants support clay, black, white and cream as supplied.
The lettering is outlined vector geometry; opening the SVGs requires no
font installation. Use the micro silhouette at small sizes. Physical
embroidery still requires a digitized stitch proof.

`README.txt` retains the upstream production notes unchanged. Its references
to a review board and an earlier exploration describe the original design
process; those files are not part of this repository import. Both hybrid
review-board files are omitted.

`PROVENANCE.json` pins the approved archive's byte count and SHA-256 and
records every member's checksum and disposition. Four SVG source originals
also appear byte-identically as runtime files in
[homepage PR #71](https://github.com/aidandaly24/goat-hoopers-site/pull/71);
they remain here as the editable production set. This import adds no site
runtime copies and does not change that PR's branch.

The selected-hybrid archive provides no standalone artwork or outlined-font
license notice. Publication preserves its existing notes and the approved
artwork; it does not invent a blanket license or claim additional upstream
rights. No font binary is added by this package.
