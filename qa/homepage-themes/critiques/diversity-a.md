## Concrete cohesion and readability defects

- **08, desktop roster-record column: fix required.** In `08-member-desktop-middle.jpg`, the right edge of each directory row wraps the intended current record into `1–` followed by `0Current`, with `W–L` isolated below. The number and its label visually run together. Give the current-record cell sufficient width or stack the value and label deliberately; preserve an unbroken record. This is a data-readability defect in the sparse grid, independent of diversity.
- **02, desktop footer brand: fix required.** `02-member-desktop-bottom.jpg` breaks the brand into `GOA / T / HOO / PERS / .` in its narrow left column, although the phone version reads coherently as `GOAT HOOPERS.`. The orphaned letters interrupt the otherwise deliberate typographic hierarchy. Give the mark enough width or use an intentional line break between complete words.
- **09, desktop league-face captions: minor spacing correction.** In `09-member-desktop-middle.jpg`, captions such as `SG · top modeled value$131.00 FAAB` visually concatenate the role/basis text and price. Put the price on a deliberate separate line or add consistent separation. The surrounding rounded color system remains coherent.

No obvious member-wide theme collapse into an unrelated generic body was found in 01–20 at the sampled native positions. Theme 18 repeats navy title strips, boxed cells and old-web navigation; 19 repeats heavy rules, narrow type and industrial register numbering; 20 repeats soft chapter fields, curved corners and portrait arches/circles into its footer. Some repeated row structures remain, as recorded in the R reasons. Uniqueness is separate from the above defects; no formal approval is implied.
