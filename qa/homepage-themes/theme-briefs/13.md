# Theme 13: Card Culture

Read ../BRIEF.md first. Edit only ../directions/13/.

- Palette: Grape, lavender, tangerine and white
- Typography: Righteous / collectible display
- Composition: Actual player/team cards as cultural objects, open supporting data
- Image/court approach: Real portraits as collectible faces, no fake scarcity or awards

Trading cards are meaningful cultural player/team objects, not generic SaaS panels. Real portraits, actual names, price basis and owner relationships. Supporting tables/lists should vary the composition. No invented rarity/awards.

No shared style/template; do not inspect another theme or old mocks before submission. All functional facts/access requirements are in the common brief. User explicitly authorizes this theme experiment only in QA, superseding older Paper + Slate visual restrictions here.
