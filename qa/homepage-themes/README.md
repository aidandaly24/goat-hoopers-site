# GOAT: twenty genuinely divergent homepage themes

This is the divergent replacement experiment after Aidan rejected #272's visual similarity. The earlier cream-paper studies remain unchanged on their own draft branch as **rejected research**, not the chosen direction. This branch starts from the preserved #271 benchmark `64b9971f88ad1f73f5bd00ac0fdef9019909561b` and changes only `qa/homepage-themes/`.

Twenty new fresh-context authors independently build full themes. They share a filesystem; blindness is an instruction boundary, not OS isolation. Three additional fresh critics are separate from the twenty authors. Common input is league facts, the functional information inventory, approved asset provenance and accessibility requirements. There is no shared CSS, theme token set, section renderer or layout template. Each author owns palette, typography, composition, density, imagery, shapes, markup and controls. Different author names alone do not establish visual diversity; actual pixels must pass an independent pairwise similarity review.

`allocation.json` records the planned palette/type/composition differences. `author-ledger.json` records actual fresh-context starts and source submissions. `BRIEF.md` carries the common facts, full information contract and access requirements. `font-catalog.json` records optional official Google Fonts assets; each retains its OFL license and metadata locally. No fonts or global skills are installed. Upstream font licenses/metadata retain their original bytes and line endings; authored-source whitespace checks exclude these vendored assets.

The theme hypotheses span neon night court, raw monochrome, broadcast network, retro arcade, championship chrome, asphalt streetball, varsity club, Swiss sport, playground illustration, court blueprint, sports terminal, league zine, trading-card culture, hardwood clubhouse, geometric sport, tunnel cinema, app-native, sports-web nostalgia, industrial gym and light Color Club. The original court is available but does not dictate every palette or composition.

## Process and delivery gate

1. Twenty independent blind first submissions with full public/member layouts.
2. Complete desktop and phone renders for every direction, not only opening crops.
3. Independent pairwise similarity critique covering palette, type, composition, image treatment, shape, density and atmosphere. Near duplicates are rejected for separate rework and remain documented.
4. Parent visual-diversity review of the whole first round before delivery. All full-size alternatives remain available.
5. Propose a diverse shortlist with visible tradeoffs, then obtain Aidan's taste signal **before** a large refinement round. Later variations stay within selected themes without erasing alternatives.

No shortlist has been selected. Design judgment is qualitative, not statistical proof. Neither an automated image distance nor separate authorship substitutes for human visual comparison.

## Run locally

```sh
python3 -m http.server 4206 --bind 127.0.0.1 --directory /absolute/path/to/repository
```

Open `/qa/homepage-themes/index.html` when the gallery is assembled. Each page is `/qa/homepage-themes/directions/NN/index.html?view=member` or `?view=public`. `?ai=stale` and `?ai=missing` exercise saved-output states.

All current records, scores, prices, form, news, moves and AI are synthetic. Dated approved identities, full rosters and editorial remain labelled with their periods. Static mocks do not establish real authentication, production Next routing/data, physical-device or spoken-screen-reader acceptance.

The primary deliverable is native full-page JPEGs with [a clear complete-image index](IMAGE-INDEX.md), avoiding a large HTML download on iOS. Every full JPEG and contact sheet is below 900 KB. [delivery-primary.json](evidence/delivery-primary.json) gives the ordered 42-file member desktop/phone delivery set; public views remain in the full index. These committed images also provide a supported parent delivery path if this executor's Library discovery remains unavailable. Native desktop/phone full-page images, including actual footer and section order, are the deliverable; contact sheets only aid browsing.

Production routes/components/configuration, databases, credentials, dependencies, #271/#272, Muse's Week 2/3D lane and recap/Power are untouched. No merge, deployment or release approval.
