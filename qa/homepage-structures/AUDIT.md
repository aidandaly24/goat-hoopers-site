# Why the previous round converged

Inspected the preserved #273 first sources at86aa682b48e2de969d910ca8aab7e1bdee004231 and rendered all20 at1440×1000. Machine observations are in prior-structure-audit.json, not a visual-quality score.

Every study used one main document scroll (5,989–12,067px), with8–16 visible major headings,21–25 native disclosures and zero independent reading panes. Nearly every sequence opens with own matchup, moves through roster value/scouting/edition/AI, then directory, standings and tools/archive. The shared fixture was data-only and authors did not import one common style template; convergence was primarily in the task framing and content anatomy.

The old brief demanded every information family be presented as a complete full page and supplied an ordered11-item inventory resembling a section outline. Assignments emphasized palette, type and cultural atmosphere. The root capture/verification infrastructure expected the entire10-team directory and all228 roster references in the same DOM for every state. That rewarded a long stacked dashboard and made focused/spatial/paged architectures harder. The critics accepted related layouts because theme/color/illustration differences were counted heavily. Their previous0near-duplicate result did not establish meaningful architectural variety, and Aidan rejected it.

Corrections in this experiment:

- Visitor jobs and factual inventory are shared without presentation order or shared wrappers. No common layout/CSS/rendering code.
- Each author gets a different architecture and navigation model, not a palette. All first wireframes are grayscale/system type so color cannot rescue a duplicate.
- Content can be reached through contextual views and navigation. Capture/testing enumerates states and traverses information; it does not require every hidden document in every default DOM.
- Phone must preserve each model's useful interaction rather than universally collapse into repeated stacked cards.
- Independent review compares all190pairs on geometry, entry point, navigation, content reveal, phone transformation and actual interaction. It must reject structurally equivalent views even if the metaphor or later palette differs. No automatic all-pass and no numeric diversity score presented as proof.
- Only accepted grayscale structures advance to full art/motion. Parent gets an early visual checkpoint; no silent shortlist.

The prior first/corrected sources and screenshots remain untouched in #273. This is a new QA-only folder/branch, not a production rearchitecture.
