Model choice is the returned roster ID, not the larger probability; confidence stays separate. `?ai=stale` retains labeled old results, while `?ai=missing` emits five honest unavailable lines with no invented choice or split. Value change is quote movement, not player form; public anchor values are not personal roster totals. No league valuation rank is asserted from incomplete comparison evidence.

Search uses native input/buttons and inserts one answer at its result origin. Escape / Back to results restores the exact trigger, Forward restores the selected answer, and no-match Return focuses the still-open commons. Search does not generate AI.
