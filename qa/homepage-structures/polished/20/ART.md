## Art and composition

Deep plum is the continuous reading surface. Warm white carries the prose. Turquoise connects the known matchup to available branches; vivid pink identifies the active endpoint, visited path and returned model's portion of the actual probability split. The open graph stays unboxed through player evidence, complete rosters, prices, all five matchups, editorial and tools. There is no repeated panel system, decorative branch numbering, study label, fake game control, texture, gradient or entrance sequence.

The GOAT mark and short known-score display use local **Press Start 2P**. All choices, team names, paragraphs, controls, large questions and long evidence use local **DM Sans**. Pixel type never carries a paragraph or the unknown-score label. Display leading permits wrapping; there is no negative tracking. The cut-step path nodes are original CSS geometry and indicate actual connections, rather than pretending to be buttons.

The original local Arcade image `/public/arcade/free-throw-preview.jpg` was visually inspected before authoring. Its dark court, clear numeric score and restrained colored control accents informed the hierarchy. It is a rendered game preview, not pixel art; no pixel-art lineage is claimed. The actual preview remains full color, uncropped at its native aspect ratio, beside the real Free Throw destination in `tools`. Approved player cutouts retain full color and bottom alignment on the local image-matte role. No new imagery or external runtime asset was added.

Desktop keeps the origin alongside the selected branch. Phone changes it into the established continuous vertical path with a compact source fact, native detail disclosure, visible parent navigation and a small Branch index. Search stays within the directory branch. The compact **Synthetic concept** disclosure retains complete fixture provenance, and stale/missing/unknown states remain labeled in context.

## Actual motion and still equivalent

Pointer selection or Back traces the actual current connection for **180ms**: the origin-to-reader segment on desktop, the active spine/heading connection on both sizes. Only connector transforms animate. The full text and controls render immediately, with normal focus and scroll restoration. A new action replaces the old node and its finite animation; no timer, RAF or loop is introduced.

Keyboard-triggered clicks, browser history and study API activations are immediate. Under reduced motion the same source, active endpoint, parent facts, branch results and return focus remain static. A live preference change removes the running trace immediately.

`motion-demo.json` contains eight total executable actions across desktop and phone. Desktop follows players → form → players → origin with pointer input. Phone combines a pointer choice, keyboard child choice, pointer Back and keyboard Back. Each bounded wait is 240ms. Both sequences were executed successfully by the verifier, not merely documented as intended behavior.
