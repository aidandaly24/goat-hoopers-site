## Motion

The only authored action animation is a **140ms pointer-triggered background confirmation on the actual added/moved player row**. Quotes and numeric totals update immediately and never tween. The effect is tied to an actual changed entity, uses semantic feedback/tray paint roles, is interruptible and stops on keyboard input, reduced-motion preference changes or hidden document state. Button pointer feedback uses only the same short background role; keyboard input removes transitions.

There are no entry/reveal animations, autonomous timers, loops, observers, staged content or scene downloads. The reduced/keyboard equivalent is the same changed membership, values, labels, polite status and focus with zero animation. `motion-demo.json` contains a four-action/wait add-and-move path with waits under 600ms.
