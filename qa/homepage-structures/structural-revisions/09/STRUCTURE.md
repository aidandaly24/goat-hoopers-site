Grayscale structure only. The original `wireframes/09/` and its evidence are preserved. Full art and independent structural acceptance remain pending. This revision responds to `reviews/critic-b.md` and the compact-phone update in `BRIEF.md`.

## Before → after

| Original rejected working model | Revised working model |
| --- | --- |
| A persistent route selector sent every subject to one interchangeable right-side reader; phone put that reader after the entire map. | There is no map selector or shared subject reader. The route branches contain the actual scores, model outputs, valuation, form, directory and editorial evidence. Native disclosures grow locally at those origins. |
| Selection meant replacing the reader's content and losing the previous subject. | Opening a branch preserves every other open branch, input and nested disclosure. Default opens both the saved-model and team-value branches. More branches can remain open concurrently. |

| One active stop was represented in the URL. | The URL/Back state contains the complete open branch set and the interaction origin. Back restores that set and focus. Search state remains in its own retained DOM. |

The change is the working/reveal model, not a revised route illustration or section order. The connecting lines now grow with actual evidence. There is no alternate renderer, detached inspector, active-topic pane or identical slot into which subjects are swapped.

## Surface contract and geometry

**User question:** Which source evidence should I inspect together to understand my current pair, team and league?

**Primary action:** Open evidence at its branch and retain another branch for context.

At desktop1440, the left arm contains the current Week 3 pair and its independently expandable model branch. The right arm contains the member identity and independently expandable value/form/wire leaves, or the public franchise faces. Default shows real model choices and real team values concurrently. The lower league register grows at its own branch; the dated editorial fork expands its own complete edition in place. Opening one draft does not close the other draft or the current evidence. A full-width open edition gives its three editorial stories their own columns; it does not send them to a topic sheet.

At phone390/320, these same branch bodies remain in natural document flow beneath their own labelled origins and connectors. Native folding reduces a branch at its own origin. The branch index reports the open count and each branch's Open/Folded state, then jumps/focuses the requested origin. It is a normal-flow disclosure, not persistent replacement navigation. The current pair is visible before any long map or full disclaimer. GOAT, Stocks, Destinations and the compact **Synthetic concept** provenance disclosure replace the old multi-link/status strips.

This is not a chronological event feed or calendar agenda. The primary paths are current pair → saved model evidence, team → current valuation/form/completed evidence, and league → local lookup. The dated editions form a separate editorial fork. They contain different source periods and job-specific working tools rather than one repeated event-row template.

Forbidden patterns remain: one interchangeable reader, exclusive branch selection, fabricated period/game dates, invented history or rankings, route decoration above a dashboard, drag/hover-only paths, modal dependence, autonomous motion and hidden essential text.

## Interaction, API and capture

Native summaries open/fold their own body. A branch operation modifies an `open` property; it does not replace another branch's HTML. Both pointer and keyboard Enter use the same local operation. The open branch set is persisted in `#open=...&at=...` and restored through Back/Forward, with focus returned to the stored origin. Local roster search remains intact when another branch opens or Back restores a set. A closed branch's summary is its return context. Escape closes the site/provenance/branch-index disclosures and returns focus to their summary; no modal or trap is used.

`body.dataset.studyReady === '09'` and `window.goatStudy` exposes eight real configurations. **Default is first and is named `default`**, matching the live initial composition.
