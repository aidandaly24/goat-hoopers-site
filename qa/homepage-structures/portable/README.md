# Self-contained local prototypes

Each NN.html contains that independently authored wireframe, the common synthetic fixture and approved image bytes; no provider/API or dependent runtime files are needed. Each is about3.2MB, under10MiB. Original source/geometry remains under wireframes/NN. Canonical outgoing league links point to goathoopers.com, and local public/member query switching is retained. These are QA concepts, not authenticated/live production pages.

The managed browser administrator rejects file:// openings. No policy flags were changed. Bundles are tested through the existing permitted localhost development server; direct offline opening on the recipient's browser is unverified. This does not block native JPEG delivery.

The first packaging test found a JavaScript replacement-string escaping bug; the compiler now preserves literal source replacement and checks each extracted module syntax before writing. Source mocks were unaffected. Both before/final packaging checks are retained.
