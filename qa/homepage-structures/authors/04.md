# Study 04: Broadcast switcher

A compact broadcast control room: a large focused program window, a narrow source slate and a persistent score rail. Choosing a source changes the program. The meaningful central view is a scoreboard/recap/personal field view, not an array of equal tiles. Mobile turns the slate into a source selector above one program. Keep all text readable, no auto crawl or fake live claims.
