# Study 20: Branching matchbook

Choosing a branch expands a connected large-type decision path with readable actual evidence; breadcrumbs/back restore the parent and retain context. No chatbot typing, fabricated AI, search or task rail. Phone uses a vertical connected decision path; all destinations also accessible directly.
