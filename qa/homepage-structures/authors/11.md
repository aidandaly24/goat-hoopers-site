# Study 11: Command index

A search-first homepage made of a giant usable query field and an open typographic action index, then direct mixed team/player/action results in the same canvas. Empty search already has useful current facts and concrete task paths. Selecting a result expands an inline contextual answer; search is local, no AI or provider. Mobile keeps query/results at the center. Distinct from task-rail workspace: no persistent sidebar or pane grid.
