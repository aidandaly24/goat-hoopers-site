# Study 10: Focused desk

A focused task workspace: one persistent narrow task/navigation rail and a single large working document, with a small contextual inspector only when needed. Default is an actionable personal/league task, not overview widgets. Tasks replace the working document; keyboard paths and back history work. Phone has one compact task picker and full-height working document. It should feel like a useful tool, not a dashboard.

Stage: grayscale working architectural wireframe only. Read ../BRIEF.md (resolved from this folder). Avoid copying any prior layout, other author or generic hero-and-card anatomy. You may choose the geometry and interaction details independently within this architecture.
